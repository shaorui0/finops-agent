# 0024 预注册的新样本外世界

- 样本外要「冻结在前」才算数：世界、标准答案、命令、决策规则先提交（A），再录制并跑一次（B），再写结果（C）。提交顺序本身就是证据，比口头保证强。
- 换一个世界，recall 从 1.0 掉到 0.75，savings_recall 掉到 0.568；三个漏检都不在判断层，在线索生成与取证。判断层 8/8 被接受、注入没生效。
- 持续异常线索抓「比历史高 2 倍」，抓不到「一直就这么高」：稳态的 NAT 大流量没有跳变也没有增长，不出线索就没有判断。上一个 change 修的是这一类的另一种形态。
- 我写的标准答案也出错：把两个 EIP、两张卷聚合成一条标准答案，评分器按单资源比金额，4 对被记范围外；还漏了停机实例上的一张 gp2 卷。事后只能记 errata，不能改原文。
- 错标的证据路径要和 agent 有的检测路径相交才算公平：我给的是 ASG 成员和 job 标签，agent 只会比 tag 与启动模板。这一条的漏检一半是世界设计的问题，一半说明 agent 归因只有一条路。
- 保留 tag 的陷阱（keep-until + owner + purpose 的 available 卷）被确定性检测器直接踩了，LLM 没参与；基础世界没有这类陷阱，所以之前没人见过。
- 坑：测试服务器写死启动模板 lt-web、lt-ingest 与若干指标标签，世界的变化幅度被限制住；这是「同一作者同一生成器」的局限，不是独立分布。
- 坑：预算 12 次，实际 8 次（$0.1507）；先在 A 之后用 FINOPS_NO_JUDGE=1 点数线索，再决定录不录。
- 结论：一个世界、n=12，区间 [0.47, 0.91]，点估计的落差真实但不能当统计显著；修了任何一条，这个世界对它就被污染，得再造新的。
