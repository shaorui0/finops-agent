# 0008-zh-docs 博客笔记

- 语言规则也是规则层的一部分：改语言先改 `rules/COMMUNICATION.md`，再改文件。否则下一个会话的 agent 会按旧规则把 README 写回英文。
- 边界划在"人读的"和"协议的"之间：文档、报告界面用中文；代码标识符、指标名、告警名、API 字段保持英文，它们要和 AWS / Prometheus 生态对得上。
- 翻译暴露了一个隐患：SLO 从线索的显示文本里用 `"starting "` 解析日期。文本一翻译，逻辑就断。改成结构化字段 `since`。逻辑不能依赖显示文本。
- 验收顺带发现报告卡片从没显示资源 ID。只看指标的验收发现不了这种"能跑但不能用"的问题，要用一个具体资源去报告里找。
