0005-pipeline-skeleton 博客笔记

  • 骨架的原则：确定性代码能算的都算掉，算不了的就老实交出一个 Lead（信号 + 证据 + 待回答的问题），不用启发式假装知道原因。第一次跑：确定性层命中 7/12，剩下 5 条全是需要跨源判断的深层发现。
  • Lead 已经指对了方向：NAT 字节从 09-04 起涨 5.5 倍；跨 AZ 流量 $760 没有资源 ID；ingest 车队”在不在干有用的活”。判断层要做的是把这些问题回答掉。
  • 真实 API 的限制会塑造方法：Cost Explorer 只给 14 天的资源级成本，所以金额口径写成 billed_14d_extrapolated，而不是假装是整月账单。
  • 归因的第一个发现：74% 的花费没有 owner——不是没打 tag，而是共享成本（NAT、跨 AZ、SP 费用）天然不挂在资源上。分摊规则本身是一个待做的决定。
  • 二八的意外项：EC2-Other（$4,676）比计算（$3,162）还大。只盯实例的成本分析从第一步就偏了。
  • 冻结快照让分析可重放：同一份 snapshot 重跑，结果一致，且零 AWS 调用。agent 出错时能精确复现。
  • trace 是 agent 可观测性的起点：每次调用的来源、操作、参数、耗时都留下来，测试里断言”全部是读操作”。
